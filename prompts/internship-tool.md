## 1. Goal & Context
Replace the legacy Smartsheet internship workflow with an automated Ensign College internal web tool, saving ~$1,500/year and streamlining student-employer-faculty internship agreement approvals.

## 2. Key Objectives
1. **Multi-Stage Approval Workflow:**
   - Stage 1: Student internship application submission.
   - Stage 2: Employer supervisor verification & work hours signoff.
   - Stage 3: Faculty coordinator (Sister Groom) review & final course authorization.
2. **Bottleneck Resolution:**
   - Resolve feedback loop delays by implementing automated reminder emails and a clear pending-action dashboard for Sister Groom.

## 3. Step-by-Step Execution
1. **Workflow Verification:**
   - Review current Smartsheet data fields and map each field to the new web tool form schema.
2. **Role-Based Access & Review Views:**
   - Implement review queues for Sister Groom and Sister Whitney.
   - Add status badges: `Pending Employer`, `Pending Faculty Review`, `Approved`, `Needs Revision`.
3. **Acceptance Testing:**
   - Run end-to-end synthetic internship approval test from student submission to final PDF agreement generation.
4. **Training & Rollout:**
   - Prepare a 1-page quick-reference guide for Sister Groom and Sister Whitney.

## 4. Done When
- Smartsheet replacement tool successfully processes end-to-end internship approval.
- Sister Groom confirms the approval bottleneck is resolved.
- Production rollout scheduled and verified.
