## How to Run a Prompt
1. Open the project in the **Key Projects Dashboard** (`https://ensign-key-projects-dashboard.vercel.app`) or **AppFix Dashboard** (`https://ensign-appfix-dashboard.vercel.app`).
2. Click the **"🚀 Start Prompt"** button on the project card.
3. Click **"📋 Copy Prompt"** to copy the full instructions to your clipboard.
4. Paste into your AI tool (Claude Code, OpenAI Codex, or Antigravity) and say "Proceed".
