## 1. Goal & Context
Adapt Ensign College Career Roadmaps 1-3 and offline on-device AI resume tutoring for incarcerated learners enrolled through the Prison and Boundless Education (PBWE) program at the Utah State Correctional Facility in Draper.

## 2. Operational Constraints
- **Strict Network Isolation:** Draper facility computers have zero internet access. All tools, models, and curriculum must operate completely offline.
- **Physical Media Security:** Software and models must be deliverable via secure offline installation packages.

## 3. Step-by-Step Execution
1. **Environment Assessment:**
   - Audit Draper Canvas offline restrictions and computer lab hardware specifications.
2. **Curriculum Adaptation:**
   - Adapt Roadmap 1 (Self-Discovery & Career Identification) for incarcerated learner contexts.
3. **Offline AI Demonstration Proposal:**
   - Package a lightweight offline LLM evaluation script suitable for standalone secure lab workstations.
4. **Instructor & Volunteer Guide:**
   - Write clear facilitator instructions for volunteer instructors.

## 4. Done When
- Roadmap 1 offline curriculum package finalized.
- Offline resume tutoring architecture reviewed and approved by PBWE leadership.
